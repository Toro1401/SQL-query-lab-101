# SQL Practice Workbook

Use this workbook to solve 101 SQL exercises and document how you checked each result. The exercises cover joins, aggregation, window functions, data quality, recursion, combinatorics, and simulations.

[Open the workbook](WORKBOOK.md) · [Read the project requirements](PRD.md)

Use the exercise ID to find your entry again. Each entry has space for your query, SQL engine and version, results, reasoning, and edge cases. Part I links to the SQL Server setup scripts. In Part II, open the exercise link for its inputs and expected results.

1. Open an exercise and set up its data on a practice database. The linked setup is written for SQL Server. If you use another engine, adapt the syntax and record the version you ran.
2. Write and run your query. Record a small result sample or a reproducible check.
3. Explain what each result row represents, how your query works, and which edge cases you checked.
4. Mark the exercise as **Verified** after reproducing the result.

All 101 solution entries are blank. Open the source for the exercise statements and sample data.
