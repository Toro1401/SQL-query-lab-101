# SQL Practice Workbook

**Status:** all 101 exercises were completed and verified on November 21, 2026 with SQLite 3.53.0 and Node.js v24.16.0. The solutions were drafted with an assistant without consulting the official SQL solutions. `Verified` covers the documented fixtures and cases. The pages for I-30 and I-51 explain their SQLite adaptations.

From the project directory, run `node verify.cjs` to check all exercises or `node verify.cjs I-13` to check one. Each exercise runs in its own in-memory database. The [setup](setup/) files recreate the data, and the [SQL files](sql/) contain the queries. The runner registers functions for hashes, checksums, and pseudorandom draws as described in the [README](README.md). See [verification/results.json](verification/results.json) for full results and [VERIFICATION.md](VERIFICATION.md) for the criteria and source corrections.

Exercise IDs follow the numbering in the source. Browse the two parts below or use the GitHub outline.

- [Part I · SQL patterns and data analysis](#part-i--sql-patterns-and-data-analysis) · 78 exercises
- [Part II · Sequences, combinations and simulations](#part-ii--sequences-combinations-and-simulations) · 23 exercises

Start with these exercises if you want to practice data analysis: [I-13](exercises/part-i/I-13.md), [I-21](exercises/part-i/I-21.md), [I-26](exercises/part-i/I-26.md), [I-27](exercises/part-i/I-27.md), [I-48](exercises/part-i/I-48.md), and [I-68](exercises/part-i/I-68.md).

Open the prompt and load the SQLite setup in a fresh database before running the query. Links to the original SQL Server setup are provided where available. The runner compares every row, including duplicates, and also checks row order in I-40. When there is no single expected output, it checks known values, invariants, or an independent JavaScript implementation. Each page shows the base result and what happened in the additional case.
