**Input:** `t1(employee_id, license)` (14 rows).

## Solution

```sql
WITH people AS (
SELECT DISTINCT employee_id id
FROM t1)
SELECT a.id,b.id,(
SELECT count(DISTINCT license)
FROM t1
WHERE employee_id=a.id)
FROM people a
CROSS
JOIN people b
WHERE a.id<>b.id AND NOT EXISTS(
SELECT license
FROM t1
WHERE employee_id=a.id EXCEPT
SELECT license
FROM t1
WHERE employee_id=b.id) AND NOT EXISTS(
SELECT license
FROM t1
WHERE employee_id=b.id EXCEPT
SELECT license
FROM t1
WHERE employee_id=a.id);
```

**Result and verification:** result 1: 4 rows. [[1001,2002,3],[2002,1001,3],[4004,5005,3],[5005,4004,3]]

## Explanation

**Method and assumptions:** each row represents an ordered pair of employees with identical license sets. The query checks the set difference in both directions.

**Edge cases and trade-offs:** adding a duplicate license leaves the full result unchanged.

```sql
INSERT INTO t1 VALUES (1001,'Class A');
```
