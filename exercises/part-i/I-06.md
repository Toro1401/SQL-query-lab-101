## Question

Which workflows have some completed steps and some unfinished steps?

## Solution

```sql
SELECT workflow
FROM t1
GROUP BY workflow
HAVING count(completion_date)>0 AND count(completion_date)<count(*);
```

## Explanation

**Method and assumptions:** A workflow is partially complete when the number of non-NULL completion dates is above zero and below the total number of steps. Using COUNT for both also meets the bonus requirement.

**Edge cases and trade-offs:** adding a workflow with no completed steps leaves the full result unchanged.

```sql
INSERT INTO t1 VALUES ('Echo',1,NULL);
```
