**Input:** `t1(order_id, distributor, facility, zone, amount)` (4 rows).

## Question

How can you assign the same numeric group key to orders with the same combination of attributes?

## Solution

```sql
SELECT dense_rank() OVER(
ORDER BY distributor,facility,zone),*
FROM t1;
```

## Explanation

**Method and assumptions:** the query gives each order the rank of its three-attribute combination. The numeric keys depend on the combinations in the current dataset.

**Edge cases and trade-offs:** an added row with the same combination receives key 1.

```sql
INSERT INTO t1 VALUES (5,'ACME',123,'ABC',1);
```
