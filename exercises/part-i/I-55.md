**Input:** `t1(product_name, quantity)` (3 rows); `t2(product_name, quantity)` (3 rows).

## Solution

```sql
SELECT CASE WHEN a.product_name IS NULL THEN 'Product does not exist in table A' WHEN b.product_name IS NULL THEN 'Product does not exist in table B' WHEN a.quantity IS b.quantity THEN 'Matches in both table A and table B' ELSE 'Quantity in table A and table B do not match' END,coalesce(a.product_name,b.product_name)
FROM t1 a
FULL
JOIN t2 b USING(product_name);
```

**Result and verification:** result 1: 4 rows. [["Matches in both table A and table B","Widget"],["Quantity in table A and table B do not match","Doodad"],["Product does not exist in table B","Gizmo"],["Product does not exist in table A","Dingbat"]]

## Explanation

**Method and assumptions:** each product name is unique within its table. The full join distinguishes missing products from differences in quantity. The query treats two NULL quantities as equal.

**Edge cases and trade-offs:** A product with NULL quantities in both tables is marked as a match.

```sql
INSERT INTO t1 VALUES ('Null',NULL); INSERT INTO t2 VALUES ('Null',NULL);
```
