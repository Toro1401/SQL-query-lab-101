**Input:** `t1(attempt_id, player_id, score)` (6 rows).

## Question

How do the attempts compare with the first and last scores, and which players improved at every step?

## Solution

```sql
WITH a AS(
SELECT *,score-first_value(score) OVER w df,score-last_value(score) OVER(PARTITION BY player_id
ORDER BY attempt_id ROWS BETWEEN UNBOUNDED PRECEDING AND UNBOUNDED FOLLOWING) dl,CASE WHEN lag(score) OVER w IS NULL OR score>lag(score) OVER w THEN 1 ELSE 0 END improved
FROM t1
WINDOW w AS(PARTITION BY player_id
ORDER BY attempt_id))
SELECT attempt_id,player_id,score,df,dl,improved,min(improved) OVER(PARTITION BY player_id)
FROM a;
```

## Explanation

**Method and assumptions:** each attempt is compared with the first and final scores. The source assigns a flag of 1 to the first attempt. To count as an overall improvement, every increase must be strictly positive.

**Edge cases and trade-offs:** when the final score matches the previous one, the overall flag for 1001 is 0.
