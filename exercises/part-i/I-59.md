**Input:** `t1(id, string)` (9 rows).

## Solution

```sql
WITH RECURSIVE r(id,original,s) AS(
SELECT id,string,string
FROM t1
UNION ALL
SELECT id,original,replace(replace(replace(s,'()',''),'[]',''),'{}','')
FROM r
WHERE s<>replace(replace(replace(s,'()',''),'[]',''),'{}',''))
SELECT id,original,CASE WHEN s='' THEN 'Balanced' ELSE 'Unbalanced' END
FROM r
WHERE s=replace(replace(replace(s,'()',''),'[]',''),'{}','');
```

**Result and verification:** result 1: 9 rows. [[7,"({)","Unbalanced"],[1,"()","Balanced"],[2,"[]","Balanced"],[3,"{}","Balanced"],[5,"()[]","Balanced"],[9,"}()[][","Unbalanced"]] … (see the report for the full output)

## Explanation

**Method and assumptions:** the query removes adjacent matching pairs until nothing changes. An empty remainder means the string is balanced. Order matters even when the counts of opening and closing brackets agree. The worst case is quadratic.

**Edge cases and trade-offs:** the crossed brackets ([)] are unbalanced even though the counts match.

```sql
INSERT INTO t1 VALUES (10,'([)]');
```
