**Input:** `t1(employee_id, manager_id, job_title)` (6 rows).

## Solution

```sql
WITH RECURSIVE h AS (
SELECT *,0 depth,','||employee_id||',' path
FROM t1
WHERE manager_id IS NULL
UNION ALL
SELECT e.*,h.depth+1,h.path||e.employee_id||','
FROM t1 e
JOIN h ON e.manager_id=h.employee_id
WHERE instr(h.path,','||e.employee_id||',')=0)
SELECT employee_id,manager_id,job_title,depth
FROM h;
```

**Result and verification:** result 1: 6 rows. [[1001,null,"CEO",0],[2002,1001,"Director",1],[3003,1001,"Office Manager",1],[4004,2002,"Engineer",2],[5005,2002,"Engineer",2],[6006,2002,"Engineer",2]]

## Explanation

**Method and assumptions:** the result has one row per employee reachable from the CEO, who starts at depth zero. The path check prevents cycles. Employees disconnected from the CEO are excluded.

**Edge cases and trade-offs:** adding an employee whose manager is missing leaves the full result unchanged.
