**Input:** `t1(temperature_id, temperature_value)` (12 rows).

## Question

How can you fill missing readings using the larger of the nearest known values on either side?

## Solution

```sql
WITH a AS(
SELECT *, (
SELECT temperature_value
FROM t1 b
WHERE b.temperature_id<a.temperature_id AND temperature_value IS NOT NULL
ORDER BY temperature_id DESC
LIMIT 1) prev,(
SELECT temperature_value
FROM t1 b
WHERE b.temperature_id>a.temperature_id AND temperature_value IS NOT NULL
ORDER BY temperature_id
LIMIT 1) next
FROM t1 a)
SELECT temperature_id,coalesce(temperature_value,CASE WHEN prev IS NULL THEN next WHEN next IS NULL THEN prev ELSE max(prev,next) END)
FROM a;
```

## Explanation

**Method and assumptions:** for each NULL reading, the query uses the larger of the nearest known readings on either side. It uses the single available neighbor at a boundary and leaves NULL if both neighbors are missing.

**Edge cases and trade-offs:** an initial NULL takes the only available neighbor, 52.
