**Input:** `t1(customer_id, phone_number)` (3 rows).

## Question

How can the database enforce a required phone number with the specified format?

## Solution

```sql
CREATE TABLE phones(customer_id INTEGER PRIMARY KEY,phone_number TEXT NOT NULL CHECK(length(phone_number)=14 AND phone_number GLOB '([0-9][0-9][0-9])-[0-9][0-9][0-9]-[0-9][0-9][0-9][0-9]'));
INSERT INTO phones
SELECT *
FROM t1;
SELECT *
FROM phones;
```

## Results

| --- | --- |
| 1001 | (555)-555-5555 |
| 2002 | (555)-555-5555 |
| 3003 | (555)-555-5555 |

## Explanation

**Method and assumptions:** each customer gets one row. CHECK enforces the length and the exact positions of ASCII digits. NOT NULL requires a phone number.

**Edge cases and trade-offs:** the constraints reject a short number, letters in digit positions, an extra digit, and NULL.
