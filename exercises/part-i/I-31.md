**Input:** `t1(integer_value)` (5 rows); `t2(name, salary)` (5 rows).

## Solution

```sql
SELECT max(integer_value)
FROM t1
WHERE integer_value<(
SELECT max(integer_value)
FROM t1);
SELECT DISTINCT integer_value
FROM t1
ORDER BY integer_value DESC
LIMIT 1 OFFSET 1;
WITH r AS(
SELECT integer_value,dense_rank() OVER(
ORDER BY integer_value DESC) r
FROM t1)
SELECT DISTINCT integer_value
FROM r
WHERE r=2;
SELECT max(salary)
FROM t2
WHERE salary<(
SELECT max(salary)
FROM t2);
```

**Result and verification:** result 1: 1 row. [[3762]] Result 2: 1 row. [[3762]] Result 3: 1 row. [[3762]] Result 4: 1 row. [[150000]]

## Explanation

**Method and assumptions:** three queries find the second distinct value. DENSE_RANK handles repeated salaries. With fewer than two distinct values, the aggregate returns NULL and the other queries return no rows. In the salary bonus, 150000 ranks second even when both top ranks have ties.

**Edge cases and trade-offs:** adding another copy of the highest value leaves the full result unchanged.
