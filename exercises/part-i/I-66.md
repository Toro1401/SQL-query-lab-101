**Input:** `t1(serial, manufacture_day, product)` (9 rows).

## Solution

```sql
WITH a AS(
SELECT *,row_number() OVER(PARTITION BY product
ORDER BY manufacture_day,serial) rn
FROM t1)
SELECT max(CASE WHEN product='Bolt' THEN serial END),max(CASE WHEN product='Washer' THEN serial END),max(CASE WHEN product='Nut' THEN serial END)
FROM a
GROUP BY rn;
```

**Result and verification:** result 1: 3 rows. [["A111","D222","G333"],["B111","E222","H333"],["C111","F222","I333"]]

## Explanation

**Method and assumptions:** each row is a kit. Components are ordered by date and serial number and matched by FIFO position within their types. Missing parts appear as NULL.

**Edge cases and trade-offs:** the last kit remains in the result with Nut set to NULL.
