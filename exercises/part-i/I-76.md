## Question

Where does each SQL batch end if the next GO separates it from the following batch?

## Solution

```sql
SELECT batch,batch_start,(
SELECT min(line)
FROM t2
WHERE t2.batch=t1.batch AND line>=batch_start AND trim(syntax)='GO')
FROM t1;
```

| A | 1 | 3 |
| A | 5 | 6 |

## Explanation

**Method and assumptions:** each row marks the beginning of a batch. The first GO on or after that row ends the batch. When GO is missing, the end is NULL. The query examines the statements without executing them.

**Edge cases and trade-offs:** A batch without GO has a NULL end.
