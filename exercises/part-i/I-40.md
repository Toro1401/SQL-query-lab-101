**Input:** `t1(city)` (4 rows).

## Question

How can you sort cities in the required custom order and put any other cities last?

## Solution

```sql
SELECT city
FROM t1
ORDER BY CASE city WHEN 'Baltimore' THEN 1 WHEN 'Denver' THEN 2 WHEN 'Atlanta' THEN 3 WHEN 'Chicago' THEN 4 ELSE 5 END,city;
```

## Results

| city |
| --- |
| Baltimore |
| Denver |
| Atlanta |
| Chicago |

## Explanation

**Method and assumptions:** the query lists cities in the specified order. Cities outside that list come last, sorted alphabetically.

**Edge cases and trade-offs:** Boston is outside the specified list and appears last.

```sql
INSERT INTO t1 VALUES ('Boston');
```
