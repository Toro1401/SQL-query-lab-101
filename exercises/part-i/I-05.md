**Input:** `t1(customer_id, type, phone_number)` (6 rows).

## Solution

```sql
SELECT customer_id,max(CASE WHEN type='Cellular' THEN phone_number END) cellular,max(CASE WHEN type='Work' THEN phone_number END) work,max(CASE WHEN type='Home' THEN phone_number END) home
FROM t1
GROUP BY customer_id;
```

**Result and verification:** result 1: 3 rows. [[1001,"555-897-5421","555-897-6542","555-698-9874"],[2002,"555-963-6544","555-812-9856",null],[3003,"555-987-6541",null,null]]

## Explanation

**Method and assumptions:** conditional aggregation produces one row per customer. If a customer has multiple numbers of the same type, the query takes the lexicographically greatest one. A real application would need an agreed rule for choosing a number.

**Edge cases and trade-offs:** for a customer with only a Home number, Cellular and Work remain NULL.
