**Input:** `t1(product, quantity)` (3 rows).

## Solution

```sql
WITH RECURSIVE n AS(
SELECT product,quantity,1 k
FROM t1
WHERE quantity>0
UNION ALL
SELECT product,quantity,k+1
FROM n
WHERE k<quantity)
SELECT product,1 quantity
FROM n;
```

**Result and verification:** result 1: 9 rows. [["Pencil",1],["Eraser",1],["Notebook",1],["Pencil",1],["Eraser",1],["Notebook",1]] … (see the report for the full output)

## Explanation

**Method and assumptions:** the query expands positive integer quantities into one row per unit. Zero quantities produce no rows.

**Edge cases and trade-offs:** adding an item with quantity zero leaves the full result unchanged.

```sql
INSERT INTO t1 VALUES ('Zero',0);
```
