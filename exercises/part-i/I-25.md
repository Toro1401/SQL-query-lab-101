**Input:** `t1(order_id, customer_id, count, vendor)` (6 rows).

## Question

Which suppliers have the most orders for each customer, including ties?

## Solution

```sql
WITH a AS(
SELECT customer_id,vendor,count(*) n
FROM t1
GROUP BY customer_id,vendor),b AS(
SELECT *,dense_rank() OVER(PARTITION BY customer_id
ORDER BY n DESC) r
FROM a)
SELECT customer_id,vendor
FROM b
WHERE r=1;
```

## Results

| customer_id | vendor |
| --- | --- |
| 1001 | Direct Parts |
| 2002 | ACME |

## Explanation

**Method and assumptions:** for each customer, the query selects the suppliers with the most orders. Each order counts once regardless of the quantity in Count. Ties are retained.

**Edge cases and trade-offs:** when both suppliers have two orders for customer 1001, both appear.
