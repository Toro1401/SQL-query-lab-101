**Input:** `t1(workflow, case_1, case_2, case_3)` (4 rows).

## Question

How many of the three checks did each workflow pass?

## Solution

```sql
SELECT workflow,case_1+case_2+case_3 passed
FROM t1;
```

## Results

| workflow | passed |
| --- | --- |
| Alpha | 0 |
| Bravo | 2 |
| Charlie | 1 |
| Delta | 0 |

## Explanation

**Method and assumptions:** each row summarizes one workflow by adding three binary flags. A missing flag leaves the total unknown.

**Edge cases and trade-offs:** three positive flags give Passed a value of 3.
