**Input:** `t1(integer_value)` (6 rows).

## Solution

```sql
DELETE
FROM t1
WHERE rowid NOT IN(
SELECT min(rowid)
FROM t1
GROUP BY integer_value);
SELECT integer_value
FROM t1;
```

**Result and verification:** result 1: 4 rows. [[1],[2],[3],[4]]

## Explanation

**Method and assumptions:** the delete removes duplicate values and keeps the row with the smallest rowid for each value. Running it a second time leaves the table unchanged.

**Edge cases and trade-offs:** adding another copy of an existing value before deletion leaves the same distinct result.
