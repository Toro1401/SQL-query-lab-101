**Status:** Verified · **SQL engine/version:** SQLite 3.53.0 (Node.js v24.16.0)

**Input:** `t1(start_date, end_date)` (5 rows).

## Solution

```sql
WITH a AS(
SELECT *,max(end_date) OVER(
ORDER BY start_date,end_date ROWS BETWEEN UNBOUNDED PRECEDING AND 1 PRECEDING) prev
FROM t1), b AS(
SELECT *,sum(prev IS NULL OR start_date>prev) OVER(
ORDER BY start_date,end_date) grp
FROM a)
SELECT min(start_date),max(end_date)
FROM b
GROUP BY grp;
```

**Result and verification:** result 1: 3 rows. [["2018-01-01","2018-01-09"],["2018-01-10","2018-01-11"],["2018-01-12","2018-01-19"]]

## Explanation

**Method and assumptions:** A running maximum of end dates allows the query to merge overlapping intervals, including nested ones. Adjacent intervals stay separate if they do not overlap.

**Edge cases and trade-offs:** adding an interval already covered by an existing one leaves the full result unchanged.
