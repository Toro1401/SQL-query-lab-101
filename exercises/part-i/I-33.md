**Input:** `t1(order_id, component, days_to_deliver)` (3 rows); `t2(product, component, days_to_manufacture)` (8 rows).

## Solution

```sql
WITH m AS(
SELECT product,max(days_to_manufacture) days
FROM t2
GROUP BY product)
SELECT order_id,component,days,days_to_deliver,CASE WHEN days=days_to_deliver THEN 'On Schedule' WHEN days>days_to_deliver THEN 'Behind Schedule' ELSE 'Ahead of Schedule' END
FROM t1
JOIN m ON product=component;
```

**Result and verification:** result 1: 3 rows. [[1,"Aurora",7,7,"On Schedule"],[2,"Twilight",7,3,"Behind Schedule"],[3,"SunRay",3,9,"Ahead of Schedule"]]

## Explanation

**Method and assumptions:** for each order, the slowest production task determines the time needed because the tasks run in parallel. Assembly is assumed to add no time.

**Edge cases and trade-offs:** when the time needed equals the maximum, the order is On Schedule.
