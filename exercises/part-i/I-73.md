**Input:** `t1(step_id, workflow, status)` (8 rows).

## Solution

```sql
SELECT a.*,(
SELECT count(DISTINCT b.status)
FROM t1 b
WHERE b.workflow=a.workflow AND b.step_id<=a.step_id)
FROM t1 a;
```

**Result and verification:** result 1: 8 rows. [[1,"Alpha","Open",1],[2,"Alpha","Open",1],[3,"Alpha","Inactive",2],[4,"Alpha","Open",2],[5,"Bravo","Closed",1],[6,"Bravo","Closed",1]] … (see the report for the full output)

## Explanation

**Method and assumptions:** for each step, the query counts the distinct statuses seen in the same workflow up to and including that step. COUNT DISTINCT ignores NULL.

**Edge cases and trade-offs:** A repeated status does not increase the distinct count.
