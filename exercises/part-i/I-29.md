**Input:** `t1(step_number, status)` (12 rows).

## Solution

```sql
WITH a AS(
SELECT *,lag(status) OVER(
ORDER BY step_number) prev
FROM t1),b AS(
SELECT *,sum(prev IS NOT status) OVER(
ORDER BY step_number) grp
FROM a)
SELECT min(step_number),max(step_number),status,count(*)
FROM b
GROUP BY grp,status;
```

**Result and verification:** result 1: 3 rows. [[1,4,"Passed",4],[5,9,"Failed",5],[10,12,"Passed",3]]

## Explanation

**Method and assumptions:** each row describes a run of adjacent, equal states in StepNumber order. A gap in step numbering does not break a run.

**Edge cases and trade-offs:** adding Failed after Passed starts a fourth run with one step.

```sql
INSERT INTO t1 VALUES (13,'Failed');
```
