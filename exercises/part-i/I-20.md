**Input:** `t1(product_id, effective_date, unit_price)` (5 rows).

## Solution

```sql
SELECT product_id,effective_date,unit_price
FROM(
SELECT *,row_number() OVER(PARTITION BY product_id
ORDER BY effective_date DESC,rowid DESC) rn
FROM t1
WHERE effective_date<='2018-12-31')
WHERE rn=1;
```

**Result and verification:** result 1: 2 rows. [[1001,"2018-06-08",3.99],[2002,"2018-05-19",2.99]]

## Explanation

**Method and assumptions:** the query selects the latest price for each product as of 2018-12-31, the reference date used to reproduce the source. When dates tie, rowid breaks the tie.

**Edge cases and trade-offs:** adding a price dated after the reference date leaves the full result unchanged.

```sql
INSERT INTO t1 VALUES (1001,'2099-01-01',99);
```
