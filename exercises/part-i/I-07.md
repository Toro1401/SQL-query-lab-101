**Status:** Verified · **SQL engine/version:** SQLite 3.53.0 (Node.js v24.16.0)

**Input:** `t1(candidate_id, description)` (10 rows); `t2(description)` (3 rows).

## Solution

```sql
SELECT DISTINCT c.candidate_id
FROM t1 c
WHERE NOT EXISTS(
SELECT 1
FROM t2 r
WHERE NOT EXISTS(
SELECT 1
FROM t1 s
WHERE s.candidate_id=c.candidate_id AND s.description=r.description));
```

**Result and verification:** result 1: 1 row. [[1001]]

## Explanation

**Method and assumptions:** each row is a candidate who has all the required skills. The query uses relational division, so a repeated requirement does not change who qualifies.

**Edge cases and trade-offs:** adding a duplicate requirement leaves the full result unchanged.

```sql
INSERT INTO t2 VALUES ('Geologist');
```
