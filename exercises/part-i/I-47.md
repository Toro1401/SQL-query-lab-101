**Input:** `t1(schedule_id, start_time, end_time)` (2 rows); `t2(schedule_id, activity, start_time, end_time)` (4 rows).

## Question

How can you split a shift into work and activity segments without counting overlapping time twice?

## Solution

```sql
WITH bounds(id,t) AS(
SELECT schedule_id,start_time
FROM t1
UNION
SELECT schedule_id,end_time
FROM t1
UNION
SELECT a.schedule_id,max(a.start_time,s.start_time)
FROM t2 a
JOIN t1 s USING(schedule_id)
WHERE a.end_time>s.start_time AND a.start_time<s.end_time
UNION
SELECT a.schedule_id,min(a.end_time,s.end_time)
FROM t2 a
JOIN t1 s USING(schedule_id)
WHERE a.end_time>s.start_time AND a.start_time<s.end_time),segments AS(
SELECT id,t,lead(t) OVER(PARTITION BY id
ORDER BY t) fin
FROM bounds)
SELECT id,coalesce((
SELECT activity
FROM t2 a
WHERE a.schedule_id=id AND a.start_time<=t AND a.end_time>=fin
ORDER BY a.rowid
LIMIT 1),'Work'),t,fin
FROM segments
WHERE fin>t;
```

## Explanation

**Method and assumptions:** each row is a segment between shift and activity boundaries. The intervals are half-open, and activities are clipped to the shift. If activities overlap, the lower rowid wins so the duration is counted once.

**Edge cases and trade-offs:** shift B has no activities, so it returns one Work segment of 120 minutes.

```sql
DELETE FROM t2 WHERE schedule_id='B';
```
