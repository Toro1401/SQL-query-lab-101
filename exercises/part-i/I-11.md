**Input:** `t1(test_case)` (3 rows).

## Question

How can you generate all permutations of the listed values without repeating a value within a permutation?

## Solution

```sql
WITH RECURSIVE p(path,used,n) AS(
SELECT '',',',0
UNION ALL
SELECT path||CASE WHEN n=0 THEN '' ELSE ',' END||test_case,used||test_case||',',n+1
FROM p
CROSS
JOIN t1
WHERE instr(used,','||test_case||',')=0)
SELECT path
FROM p
WHERE n=(
SELECT count(*)
FROM t1);
```

## Results

| path |
| --- |
| A,B,C |
| A,C,B |
| B,A,C |
| B,C,A |
| C,A,B |
| C,B,A |

## Explanation

**Method and assumptions:** each row is a permutation without repetition. The inputs must be distinct and contain no commas. The permutation length comes from the data.

**Edge cases and trade-offs:** adding D gives 24 distinct permutations of 4 elements each.

```sql
INSERT INTO t1 VALUES ('D');
```
