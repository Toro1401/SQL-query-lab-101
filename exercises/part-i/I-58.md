## Question

How can you evaluate integer expressions containing addition and subtraction with SQL?

## Solution

```sql
WITH RECURSIVE r(e,p,total,term,sgn) AS(
SELECT equation,1,0,0,1
FROM t1
UNION ALL
SELECT e,p+1,CASE WHEN substr(e,p,1) IN('+','-') THEN total+sgn*term ELSE total END,CASE WHEN substr(e,p,1) IN('+','-') THEN 0 ELSE term*10+cast(substr(e,p,1) AS INTEGER) END,CASE substr(e,p,1) WHEN '+' THEN 1 WHEN '-' THEN -1 ELSE sgn END
FROM r
WHERE p<=length(e))
SELECT e,total+sgn*term
FROM r
WHERE p=length(e)+1;
```

## Results

| e | total+sgn*term |
| --- | --- |
| 123 | 123 |
| 1+23 | 24 |
| 1-23 | -22 |
| 12+3 | 15 |
| 12-3 | 9 |
| 1+2+3 | 6 |
| 1+2-3 | 0 |
| 1-2+3 | 2 |
| 1-2-3 | -4 |

## Explanation

**Method and assumptions:** the recursive parser evaluates one integer expression per row. It handles digits, plus, and minus without executing the text as code. Spaces and parentheses are outside its input domain.

**Edge cases and trade-offs:** the expression 10-20+3 returns -7.
