**Input:** `t1(friend_1, friend_2)` (6 rows).

## Solution

```sql
WITH e(a,b) AS(
SELECT friend_1,friend_2
FROM t1
UNION
SELECT friend_2,friend_1
FROM t1)
SELECT a,b,(
SELECT count(*)
FROM e x
JOIN e y ON x.b=y.b
WHERE x.a=e.a AND y.a=e.b)
FROM e
WHERE a<b;
```

**Result and verification:** result 1: 6 rows. [["Jason","Mary",2],["Jason","Mike",1],["Jason","Susan",1],["John","Mary",0],["Mary","Mike",1],["Mary","Susan",1]]

## Explanation

**Method and assumptions:** each row is a friendship stored in a canonical order. The query counts neighbors shared by both people in the undirected graph. Duplicate friendships are ignored.

**Edge cases and trade-offs:** adding the same friendship in reverse order leaves the full result unchanged.

```sql
INSERT INTO t1 VALUES ('Mary','Jason');
```
