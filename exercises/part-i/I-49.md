**Input:** `t1(line_order, name, weight)` (6 rows).

## Solution

```sql
WITH a AS(
SELECT *,sum(weight) OVER(
ORDER BY line_order ROWS UNBOUNDED PRECEDING) total
FROM t1)
SELECT name
FROM a
WHERE total<=2000
ORDER BY line_order DESC
LIMIT 1;
```

**Result and verification:** result 1: 1 row. [["Haruki"]]

## Explanation

**Method and assumptions:** the query returns the last person in the queue whose running weight total is at most 2000. All weights are positive and people cannot be skipped.

**Edge cases and trade-offs:** if the first athlete exceeds the limit, nobody enters.

