**Input:** `t1(game_id, bowler, score)` (8 rows).

## Question

Which pairs of players were next to each other in the standings?

## Solution

```sql
WITH a AS(
SELECT game_id,bowler,lead(bowler) OVER(PARTITION BY game_id
ORDER BY score DESC,bowler) next
FROM t1),b AS(
SELECT min(bowler,next) lo,max(bowler,next) hi
FROM a
WHERE next IS NOT NULL)
SELECT lo,hi,count(*)
FROM b
GROUP BY lo,hi;
```

## Results

| lo | hi | count(*) |
| --- | --- | --- |
| Anthony | Dennis | 1 |
| Dennis | John | 1 |
| John | Susan | 2 |
| Mary | Ralph | 1 |
| Ralph | Susan | 1 |

## Explanation

**Method and assumptions:** the query pairs adjacent players in the rankings. It sorts scores in descending order, breaks ties by name, and puts each pair's names in alphabetical order.

**Edge cases and trade-offs:** adding a league with a single player leaves the full result unchanged.

```sql
INSERT INTO t1 VALUES (3,'Solo',100);
```
