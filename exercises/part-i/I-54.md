**Input:** `t1(number)` (3 rows); `t2(ticket_id, number)` (9 rows).

## Solution

```sql
WITH m AS(
SELECT ticket_id,count(DISTINCT CASE WHEN number IN(
SELECT number
FROM t1) THEN number END) n
FROM t2
GROUP BY ticket_id)
SELECT coalesce(sum(CASE WHEN n=(
SELECT count(DISTINCT number)
FROM t1) AND n>0 THEN 100 WHEN n>0 THEN 10 ELSE 0 END),0)
FROM m;
```

**Result and verification:** result 1: 1 row. [[110]]

## Explanation

**Method and assumptions:** the result is one row with the total payout. A ticket pays 100 if it contains all winning numbers or 10 if it contains some of them.

**Edge cases and trade-offs:** adding a non-winning number to a ticket leaves the full result unchanged.
