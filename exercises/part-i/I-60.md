**Input:** `t1(product, product_code)` (4 rows).

## Solution

```sql
SELECT product_code
FROM t1
GROUP BY product_code
HAVING count(DISTINCT product)=1;
```

**Result and verification:** result 1: 2 rows. [["01"],["03"]]

## Explanation

**Method and assumptions:** A code appears if it is linked to exactly one distinct product. Codes stay as text to preserve leading zeros.

**Edge cases and trade-offs:** adding a duplicate association for the same product leaves the full result unchanged.

```sql
INSERT INTO t1 VALUES ('Alpha','01');
```
