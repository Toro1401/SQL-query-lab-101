**Input:** `t1(associate_1, associate_2)` (6 rows).

## Question

Which identifiers belong to the same connected component?

## Solution

```sql
WITH RECURSIVE edges(a,b) AS(
SELECT *
FROM t1
UNION
SELECT associate_2,associate_1
FROM t1),reach(root,node) AS(
SELECT a,a
FROM edges
UNION
SELECT root,b
FROM reach
JOIN edges ON a=node),components AS(
SELECT node,min(root) root
FROM reach
GROUP BY node)
SELECT dense_rank() OVER(
ORDER BY root),node
FROM components;
```

## Explanation

**Method and assumptions:** the query returns one row per node in the undirected graph. The smallest name identifies each connected component. UNION discards repeated visits and lets the recursion finish even if the graph contains a cycle.

**Edge cases and trade-offs:** adding another connection within the same component leaves the full result unchanged.
