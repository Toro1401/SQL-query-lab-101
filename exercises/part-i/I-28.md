## Question

How can you fill a missing value with the last known value before it?

## Solution

```sql
SELECT row_number,(
SELECT b.test_case
FROM t1 b
WHERE b.row_number<=a.row_number AND b.test_case IS NOT NULL
ORDER BY b.row_number DESC
LIMIT 1)
FROM t1 a;
```

## Explanation

**Method and assumptions:** for each position, the query uses the current value if known or carries forward the last known value before it.

**Edge cases and trade-offs:** an initial NULL remains NULL because there is no earlier value to carry forward.

