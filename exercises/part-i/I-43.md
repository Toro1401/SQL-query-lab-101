**Input:** `t1(order_id, customer_id, quantity)` (6 rows).

## Question

What is the running minimum order value for each customer?

## Solution

```sql
SELECT *,min(quantity) OVER(PARTITION BY customer_id
ORDER BY order_id ROWS UNBOUNDED PRECEDING)
FROM t1;
```

## Results

| order_id | customer_id | quantity | min(quantity) OVER(PARTITION BY customer_id<br>ORDER BY order_id ROWS UNBOUNDED PRECEDING) |
| --- | --- | --- | --- |
| 1 | 1001 | 5 | 5 |
| 2 | 1001 | 8 | 5 |
| 3 | 1001 | 3 | 3 |
| 4 | 1001 | 7 | 3 |
| 1 | 2002 | 4 | 4 |
| 2 | 2002 | 9 | 4 |

## Explanation

**Method and assumptions:** each order shows the running minimum for its customer. OrderID must be unique within a customer so the window has a consistent order.

**Edge cases and trade-offs:** A new minimum of 1 for customer 1001 changes only that customer's window.

```sql
INSERT INTO t1 VALUES (5,1001,1);
```
