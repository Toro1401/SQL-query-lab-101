**Input:** `t1(spaceman_id, job_description, mission_count)` (9 rows).

## Question

Who flew the most and fewest missions in each profession?

## Solution

```sql
SELECT job_description,(
SELECT spaceman_id
FROM t1 b
WHERE b.job_description=a.job_description
ORDER BY mission_count DESC,spaceman_id
LIMIT 1),(
SELECT spaceman_id
FROM t1 b
WHERE b.job_description=a.job_description
ORDER BY mission_count,spaceman_id
LIMIT 1)
FROM t1 a
GROUP BY job_description;
```

## Explanation

**Method and assumptions:** each profession gets the IDs with the highest and lowest mission counts. The lower ID wins a tie.

**Edge cases and trade-offs:** adding a tied employee with a larger ID leaves the full result unchanged.
