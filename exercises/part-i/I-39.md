**Input:** `t1(integer_value)` (10 rows).

## Question

Which input numbers are prime?

## Solution

```sql
WITH RECURSIVE n(x) AS(
SELECT 2
UNION ALL
SELECT x+1
FROM n
WHERE x*x<=(
SELECT max(integer_value)
FROM t1))
SELECT integer_value
FROM t1
WHERE integer_value>1 AND NOT EXISTS(
SELECT 1
FROM n
WHERE x*x<=integer_value AND integer_value%x=0);
```

## Results

| integer_value |
| --- |
| 2 |
| 3 |
| 5 |
| 7 |

## Explanation

**Method and assumptions:** each row is a prime number. The query tests possible divisors up to the square root and excludes 1 and negative numbers.

**Edge cases and trade-offs:** adding 49 leaves the full result unchanged because 7 divides it.

```sql
INSERT INTO t1 VALUES (49);
```
