## Question

Which boxes are equivalent when rotations are allowed?

## Solution

```sql
WITH a AS(
SELECT box_id,min(length,width,height) lo,max(length,width,height) hi,length+width+height-min(length,width,height)-max(length,width,height) mid
FROM t1)
SELECT box_id,dense_rank() OVER(
ORDER BY lo,mid,hi)
FROM a;
```

## Explanation

**Method and assumptions:** the query sorts each box's three dimensions to give equivalent rotations the same group. It assumes positive, non-NULL dimensions.

**Edge cases and trade-offs:** A rotated version of A or B stays in group 1.
