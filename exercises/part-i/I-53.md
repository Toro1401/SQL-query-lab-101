**Input:** `t1(primary_id, spouse_id)` (6 rows).

## Question

How can you identify reciprocal partner pairs and assign each a group ID?

## Solution

```sql
SELECT dense_rank() OVER(
ORDER BY max(primary_id,spouse_id)),primary_id,spouse_id
FROM t1;
```

## Explanation

**Method and assumptions:** each row represents one person. The query ranks reciprocal pairs by the lexicographically larger member, matching the GroupID convention in the source.

**Edge cases and trade-offs:** the new pair gets group 4.
