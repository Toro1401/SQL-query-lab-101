**Input:** `t1(route_id, departure_city, arrival_city, cost)` (4 rows).

## Solution

```sql
WITH RECURSIVE r(city,path,cost,visited) AS(
SELECT 'Austin','Austin',0,',Austin,'
UNION ALL
SELECT arrival_city,path||' --> '||arrival_city,r.cost+t1.cost,visited||arrival_city||','
FROM r
JOIN t1 ON departure_city=city
WHERE city<>'Des Moines' AND instr(visited,','||arrival_city||',')=0)
SELECT path,cost
FROM r
WHERE city='Des Moines';
```

**Result and verification:** result 1: 2 rows. [["Austin --> Dallas --> Des Moines",500],["Austin --> Dallas --> Memphis --> Des Moines",600]]

## Explanation

**Method and assumptions:** each row is a simple route from Austin to Des Moines. The visited path prevents cycles and repeated cities. The fixture has a minimum route cost of 500 and a maximum of 600.

**Edge cases and trade-offs:** adding a link back to Austin leaves the full result unchanged because it would repeat a city.
