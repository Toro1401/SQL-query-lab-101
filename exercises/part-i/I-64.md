## Question

Which strings contain exactly two quotation marks with more than ten characters between them?

## Solution

```sql
WITH a AS(
SELECT *,length(string)-length(replace(string,'"','')) n,instr(string,'"') p
FROM t1)
SELECT id,string,CASE WHEN n<>2 THEN 'Error' WHEN instr(substr(string,p+1),'"')-1>10 THEN 'True' ELSE 'False' END
FROM a;
```

## Explanation

**Method and assumptions:** the query checks each string for exactly two quotation marks and more than 10 characters between them. It returns Error when there is only one quote, a case the source leaves open.

**Edge cases and trade-offs:** exactly ten characters between quotes returns False.
