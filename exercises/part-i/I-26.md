**Input:** `t1(year, amount)` (6 rows).

## Solution

```sql
SELECT sum(CASE WHEN year=2018 THEN amount ELSE 0 END) AS "2018",sum(CASE WHEN year=2017 THEN amount ELSE 0 END) AS "2017",sum(CASE WHEN year=2016 THEN amount ELSE 0 END) AS "2016"
FROM t1;
```

**Result and verification:** source correction: 159521 + 251696 + 111894 = 523111 for 2016. The expected value of 411217 omits 111894. Result 1: 1 row. [[352645,420219,523111]]

## Explanation

**Method and assumptions:** one row summarizes 2018 and the two preceding years. Each column sums all sales for that year and shows zero if the year has no sales.

**Edge cases and trade-offs:** adding a sale in 2015 leaves all three totals unchanged.

```sql
INSERT INTO t1 VALUES (2015,999);
```
