**Input:** `t1(customer_id, balance_date, amount)` (10 rows).

## Question

How can you derive the effective date range of each version from its start date?

## Solution

```sql
SELECT customer_id,balance_date,coalesce(date(lead(balance_date) OVER(PARTITION BY customer_id
ORDER BY balance_date),'-1 day'),'9999-12-31'),amount
FROM t1;
```

## Explanation

**Method and assumptions:** each customer version covers an inclusive date range. The start dates must be unique for each customer. A version ends the day before the next one begins, and the latest version stays open.

**Edge cases and trade-offs:** A customer with a single version gets 9999-12-31 as its end date.
