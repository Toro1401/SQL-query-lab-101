**Input:** `t1(customer_id, start_date, end_date, amount)` (6 rows).

## Question

Which earlier record versions overlap the start of a later version for the same customer?

## Solution

```sql
SELECT *
FROM t1 a
WHERE EXISTS(
SELECT 1
FROM t1 b
WHERE b.customer_id=a.customer_id AND b.start_date>a.start_date AND b.start_date<=a.end_date);
```

## Results

| customer_id | start_date | end_date | amount |
| --- | --- | --- | --- |
| 1001 | 2021-09-18 | 2021-10-12 | 65.56 |
| 2002 | 2021-09-01 | 2021-09-17 | 42.12 |

## Explanation

**Method and assumptions:** the query selects the earlier version when its inclusive interval overlaps the start of a later one. Selecting only the earlier version follows the source convention.

**Edge cases and trade-offs:** adding a non-overlapping version leaves the full result unchanged.

```sql
INSERT INTO t1 VALUES (3003,'2021-01-01','2021-01-02',0);
```
