## Question

How can you split the input into tokens and report their positions, including empty tokens between spaces?

## Solution

```sql
WITH RECURSIVE w(id,string,start,rest,rn) AS(
SELECT rowid,statement,1,statement,1
FROM t1
UNION ALL
SELECT id,string,start+instr(rest,' '),substr(rest,instr(rest,' ')+1),rn+1
FROM w
WHERE instr(rest,' ')>0)
SELECT rn,id,string,start,start+length(CASE WHEN instr(rest,' ')=0 THEN rest ELSE substr(rest,1,instr(rest,' ')-1) END)-1,CASE WHEN instr(rest,' ')=0 THEN rest ELSE substr(rest,1,instr(rest,' ')-1) END
FROM w;
```

## Explanation

**Method and assumptions:** the query returns one token per row, with positions starting at 1. The semicolon stays in the token. Consecutive spaces produce explicit empty tokens.

**Edge cases and trade-offs:** two spaces between A and B produce an empty token.

```sql
INSERT INTO t1 VALUES ('A  B');
```
