**Input:** `t1(workflow, message, occurrences)` (8 rows).

## Solution

```sql
WITH a AS(
SELECT workflow,message,sum(occurrences) n
FROM t1
GROUP BY workflow,message),b AS(
SELECT *,dense_rank() OVER(PARTITION BY message
ORDER BY n DESC) r
FROM a)
SELECT workflow,message,n
FROM b
WHERE r=1;
```

**Result and verification:** result 1: 4 rows. [["Bravo","Error: cannot Divide by 0",3],["Charlie","Error: conversion Failed",7],["Charlie","Error: unidentified error occurred",10],["Alpha","Status Complete",8]]

## Explanation

**Method and assumptions:** the query counts occurrences of each message by workflow and returns all workflows tied for the highest count for that message.

**Edge cases and trade-offs:** when Alpha and Tie match for Status Complete, both appear.

```sql
INSERT INTO t1 VALUES ('Tie','Status Complete',8);
```
