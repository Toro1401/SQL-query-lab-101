## Solution

```sql
CREATE TABLE products_data(product_id INTEGER PRIMARY KEY,product_name TEXT);
INSERT INTO products_data VALUES (1,'Widget');
CREATE VIEW products AS
SELECT product_id,product_name,forbid_star() AS forbidden
FROM products_data;
SELECT product_id,product_name
FROM products;
```

**Result and verification:** result 1: 1 row. [[1,"Widget"]]

## Explanation

**Method and assumptions:** this SQLite adaptation uses a view with a sentinel column that raises an error when SELECT * reads it. Explicitly named columns remain readable. The runner registers forbid_star(). The sentinel demonstrates query behavior and does not provide access control.

**Edge cases and trade-offs:** selecting the two columns explicitly succeeds. SELECT * raises Explicit columns required.
