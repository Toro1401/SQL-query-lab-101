## Question

How can you derive one workflow status from its individual step statuses?

## Solution

```sql
SELECT workflow,CASE WHEN count(DISTINCT status)=1 THEN min(status) WHEN sum(status='Error')>0 THEN 'Indeterminate' ELSE 'Running' END
FROM t1
GROUP BY workflow;
```

## Explanation

**Method and assumptions:** the query returns one status per workflow. If all statuses agree, it keeps that status. A mix that includes an error is indeterminate. Otherwise, the workflow is running. The input statuses are non-NULL.

**Edge cases and trade-offs:** A mix of Error and Running returns Indeterminate.

```sql
INSERT INTO t1 VALUES ('Foxtrot',1,'Error'); INSERT INTO t1 VALUES ('Foxtrot',2,'Running');
```
