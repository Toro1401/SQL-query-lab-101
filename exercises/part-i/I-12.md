## Question

What is the average time between consecutive events in each workflow?

## Solution

```sql
WITH d AS(
SELECT workflow,julianday(execution_date)-julianday(lag(execution_date) OVER(PARTITION BY workflow
ORDER BY execution_date)) gap
FROM t1)
SELECT workflow,cast(avg(gap) AS INTEGER)
FROM d
GROUP BY workflow;
```

## Results

| workflow | cast(avg(gap) AS INTEGER) |
| --- | --- |
| Alpha | 7 |
| Bravo | 9 |
| Charlie | 14 |

## Explanation

**Method and assumptions:** for each workflow, the query averages the intervals between consecutive events and truncates the result to match the source. A workflow with one event has no interval to average.

**Edge cases and trade-offs:** A workflow with just one event returns NULL for the average interval.
