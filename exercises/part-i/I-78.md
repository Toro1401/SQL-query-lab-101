**Input:** `t1(statusid, status)` (4 rows); `t2(statuscode)` (1 row).

## Question

How can you return the status rows only when the codes table contains at least one row?

## Solution

```sql
SELECT *
FROM t1
WHERE EXISTS(
SELECT 1
FROM t2);
```

## Explanation

**Method and assumptions:** the query returns one row per status if the codes table is non-empty. EXISTS checks for any match without multiplying the rows.

**Edge cases and trade-offs:** an empty codes table yields no status rows.

```sql
DELETE FROM t2;
```
