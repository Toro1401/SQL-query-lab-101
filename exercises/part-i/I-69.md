**Input:** `t1(parent, child)` (6 rows).

## Solution

```sql
WITH RECURSIVE roots AS(
SELECT DISTINCT parent root
FROM t1
WHERE parent NOT IN(
SELECT child
FROM t1)),seeds AS(
SELECT root,child,dense_rank() OVER(
ORDER BY root,child) grp
FROM roots
JOIN t1 ON parent=root),r(grp,node) AS(
SELECT grp,root
FROM seeds
UNION
SELECT grp,child
FROM seeds
UNION
SELECT r.grp,t1.child
FROM r
JOIN t1 ON parent=node
WHERE node NOT IN(
SELECT root
FROM roots))
SELECT grp,node
FROM r;
```

**Result and verification:** result 1: 8 rows. [[1,"A"],[1,"B"],[2,"A"],[2,"C"],[1,"D"],[1,"E"]] … (see the report for the full output)

## Explanation

**Method and assumptions:** each row gives a node and its main branch. The root appears in every group. The groups follow the order of the root's children, and UNION limits duplication.

**Edge cases and trade-offs:** H is a child of E and belongs to branch 1.

```sql
INSERT INTO t1 VALUES ('E','H');
```
