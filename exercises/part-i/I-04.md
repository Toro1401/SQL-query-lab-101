**Input:** `t1(customer_id, order_id, delivery_state, amount)` (8 rows).

## Solution

```sql
SELECT *
FROM t1 o
WHERE delivery_state='TX' AND EXISTS(
SELECT 1
FROM t1 c
WHERE c.customer_id=o.customer_id AND c.delivery_state='CA');
```

**Result and verification:** result 1: 3 rows. [[1001,2,"TX",950],[1001,3,"TX",670],[1001,4,"TX",860]]

## Explanation

**Method and assumptions:** each row is a TX order from a customer with at least one CA order. EXISTS checks for a match without duplicating the TX orders.

**Edge cases and trade-offs:** adding another CA order for the same customer leaves the full result unchanged.

```sql
INSERT INTO t1 VALUES (1001,9,'CA',10);
```
