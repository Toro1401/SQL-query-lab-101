## Question

Which orders contain exactly one distinct product and use the same qualifying promotion on every line?

## Solution

```sql
SELECT order_id
FROM t1
GROUP BY order_id
HAVING count(DISTINCT product)=1 AND count(product)=count(*) AND sum(discount IS NOT 'PROMO')=0;
```

## Results

| order_id |
| --- |
| 3 |

## Explanation

**Method and assumptions:** an order qualifies when it contains exactly one product and every row has the PROMO discount. Duplicate rows are allowed. A NULL discount fails the check.

**Edge cases and trade-offs:** adding a NULL discount excludes order 3.

```sql
INSERT INTO t1 VALUES (3,'Item 1',NULL);
```
