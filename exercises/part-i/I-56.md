## Solution

```sql
WITH RECURSIVE n(x) AS(
SELECT 1
UNION ALL
SELECT x+1
FROM n
WHERE x<10)
SELECT x
FROM n;
```

**Result and verification:** result 1: 10 rows. [[1],[2],[3],[4],[5],[6]] … (see the report for the full output)

## Explanation

**Method and assumptions:** the recursion returns one integer per row from 1 through 10. The recursive step has an explicit stopping condition.

**Edge cases and trade-offs:** creating an unrelated table still gives the same ten consecutive rows.
