**Input:** `t1(integer_value)` (11 rows).

## Question

What are the mean, median, mode, and range of the values?

## Solution

```sql
WITH r AS(
SELECT integer_value v,row_number() OVER(
ORDER BY integer_value) rn,count(*) OVER() n
FROM t1)
SELECT (
SELECT avg(1.0*integer_value)
FROM t1) mean,(
SELECT avg(1.0*v)
FROM r
WHERE rn IN ((n+1)/2,(n+2)/2)) median,(
SELECT integer_value
FROM t1
GROUP BY integer_value
ORDER BY count(*) DESC,integer_value
LIMIT 1) mode,(
SELECT max(integer_value)-min(integer_value)
FROM t1) range;
```

## Results

| mean | median | mode | range |

| 31.09090909090909 | 14 | 10 | 85 |

## Explanation

**Method and assumptions:** the summary row contains a non-integer mean where applicable, the median, the mode, and the range. If several values tie for the mode, the smallest wins.

**Edge cases and trade-offs:** for 1, 2, 3, and 4, the mean and median are 2.5, the selected mode is 1, and the range is 3.
