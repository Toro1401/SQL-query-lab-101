**Input:** `t1(trials, seed)` (1 row).

## Solution

```sql
WITH RECURSIVE n(x) AS(
SELECT 1
UNION ALL
SELECT x+1
FROM n
WHERE x<(
SELECT trials
FROM t1)),doors(d) AS(VALUES(1),(2),(3)),draws AS MATERIALIZED(
SELECT x,1+rnd(x*2+(
SELECT seed
FROM t1))%3 prize,1+rnd(x*2+1+(
SELECT seed
FROM t1))%3 choice
FROM n),host AS(
SELECT *,(
SELECT min(d)
FROM doors
WHERE d<>prize AND d<>choice) opened
FROM draws)
SELECT count(*),sum(prize=choice),sum(prize=6-choice-opened),sum(opened=prize OR opened=choice)
FROM host;
```

**Result and verification:** result 1: 1 row. [[10000,3427,6573,0]]

## Explanation

**Method and assumptions:** one row summarizes 10,000 trials, including wins for staying and switching and the count of invalid openings. The host knows where the prize is and opens a door with a goat. Switching has a theoretical win probability of about 2/3, which the simulation estimates.

**Edge cases and trade-offs:** in a single trial, exactly one strategy wins and the host opens a valid door.
