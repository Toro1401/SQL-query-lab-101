**Input:** `t1(x, y)` (1 row).

## Question

Which squares can the knight reach in one legal move from 4D?

## Solution

```sql
WITH offsets(dx,dy) AS(VALUES(1,2),(1,-2),(-1,2),(-1,-2),(2,1),(2,-1),(-2,1),(-2,-1))
SELECT (x+dx)||char(64+y+dy)
FROM t1
CROSS
JOIN offsets
WHERE x+dx BETWEEN 1 AND 8 AND y+dy BETWEEN 1 AND 8;
```

## Explanation

**Method and assumptions:** the query tries all eight L-shaped offsets from 4D and returns one row per legal move. Both coordinates must stay within 1 through 8. The exercise asks for the next move, so the query stops after one jump.

**Edge cases and trade-offs:** from corner 1A, the only legal moves are 2C and 3B.

```sql
UPDATE t1 SET x=1,y=1;
```
