**Input:** `t1(n)` (1 row).

## Solution

```sql
WITH RECURSIVE ops(o) AS(VALUES(''),('+'),('-')),r(k,s,total,term,sign) AS(
SELECT 1,'1',0,1,1
UNION ALL
SELECT k+1,s||o||(k+1),CASE WHEN o='' THEN total ELSE total+sign*term END,CASE WHEN o='' THEN term*10+(k+1) ELSE k+1 END,CASE WHEN o='-' THEN -1 WHEN o='+' THEN 1 ELSE sign END
FROM r
CROSS
JOIN ops
WHERE k<(
SELECT n
FROM t1))
SELECT s,total+sign*term
FROM r
WHERE k=(
SELECT n
FROM t1);
```

**Result and verification:** result 1: 9 rows. [["123",123],["12+3",15],["12-3",9],["1+23",24],["1+2+3",6],["1+2-3",0]] … (see the report for the full output)

## Explanation

**Method and assumptions:** each row chooses concatenation, addition, or subtraction between the digits from 1 through n. The supported range is n=1 through 9, with 3^(n-1) combinations. The query builds the sum without evaluating the expression as code.

**Edge cases and trade-offs:** with n=1 there are no operators, and the value is 1.

```sql
UPDATE t1 SET n=1;
```
