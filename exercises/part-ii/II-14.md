**Input:** `t1(n, k)` (1 row).

## Question

Who survives when every kth person is removed from a circle?

## Solution

```sql
WITH RECURSIVE j(n,s) AS(VALUES(1,0)
UNION ALL
SELECT n+1,(s+(
SELECT k
FROM t1))%(n+1)
FROM j
WHERE n<(
SELECT n
FROM t1))
SELECT s+1
FROM j
WHERE n=(
SELECT n
FROM t1);
```

## Results

| s+1 |
| --- |
| 4 |

## Explanation

**Method and assumptions:** the query returns the survivor of the Josephus problem. With n=7, it starts counting at person 1, counts that person, and eliminates every third person. It converts the zero-based recurrence to a one-based answer.

**Edge cases and trade-offs:** with just one person, the survivor is 1.

```sql
UPDATE t1 SET n=1;
```
