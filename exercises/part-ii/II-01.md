**Status:** Verified · **SQL engine/version:** SQLite 3.53.0 (Node.js v24.16.0)

**Input:** `t1(n)` (1 row).

## Solution

```sql
WITH RECURSIVE f(n,v) AS(
SELECT 1,1
WHERE (
SELECT n
FROM t1)>0
UNION ALL
SELECT n+1,v*(n+1)
FROM f
WHERE n<(
SELECT n
FROM t1))
SELECT n,v
FROM f;
```

**Result and verification:** result 1: 10 rows. [[1,1],[2,2],[3,6],[4,24],[5,120],[6,720]] … (see the report for the full output)

## Explanation

**Method and assumptions:** the query returns each integer from 1 through n and its factorial. Results are exact through 20! in a signed 64-bit SQLite integer. Larger values require arbitrary-precision integers.

**Edge cases and trade-offs:** with n=1, the result is a single row (1,1).

```sql
UPDATE t1 SET n=1;
```
