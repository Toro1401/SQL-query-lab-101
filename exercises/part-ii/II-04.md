**Input:** `t1(n)` (1 row).

## Question

Which permutations have no adjacent values that differ by 1?

## Solution

```sql
WITH RECURSIVE nums(x) AS(
SELECT 1
UNION ALL
SELECT x+1
FROM nums
WHERE x<(
SELECT n
FROM t1)),p(path,mask,k,last) AS(
SELECT '',0,0,0
UNION ALL
SELECT path||CASE WHEN k=0 THEN '' ELSE ',' END||x,mask|(1<<x),k+1,x
FROM p
CROSS
JOIN nums
WHERE (mask&(1<<x))=0 AND (k=0 OR abs(x-last)>1))
SELECT path
FROM p
WHERE k=(
SELECT n
FROM t1);
```

## Results

| path |
| --- |
| 2,4,1,3 |
| 3,1,4,2 |

## Explanation

**Method and assumptions:** each row is a permutation in which adjacent values do not differ by 1. Using n=4 reproduces the two expected rows. The description uses n=10 as an example.

**Edge cases and trade-offs:** there are no valid permutations for n=3.

```sql
UPDATE t1 SET n=3;
```
