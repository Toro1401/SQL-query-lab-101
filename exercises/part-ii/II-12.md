## Question

What sequence do you get by doubling while the next value stays below 100 and adding 1 afterward?

## Solution

```sql
WITH RECURSIVE r(x) AS(VALUES(1)
UNION ALL
SELECT CASE WHEN 2*x<100 THEN 2*x ELSE x+1 END
FROM r
WHERE CASE WHEN 2*x<100 THEN 2*x ELSE x+1 END<=(
SELECT stop
FROM t1))
SELECT x
FROM r;
```

## Explanation

**Method and assumptions:** the query returns one row per generated number. It doubles when the result would be below 100, then adds 1 at a time. The source gives no endpoint, so the setup uses a limit of 110.

**Edge cases and trade-offs:** with a limit of 1, only the seed value appears.

```sql
UPDATE t1 SET stop=1;
```
