**Input:** `t1(seat_number)` (16 rows).

## Solution

```sql
WITH RECURSIVE n(x) AS(
SELECT 1
WHERE (
SELECT max(seat_number)
FROM t1)>=1
UNION ALL
SELECT x+1
FROM n
WHERE x<(
SELECT max(seat_number)
FROM t1)), missing AS(
SELECT x
FROM n
WHERE NOT EXISTS(
SELECT 1
FROM t1
WHERE seat_number=x)), g AS(
SELECT x,x-row_number() OVER(
ORDER BY x) grp
FROM missing)
SELECT min(x),max(x)
FROM g
GROUP BY grp
ORDER BY min(x);
WITH RECURSIVE n(x) AS(
SELECT 1
UNION ALL
SELECT x+1
FROM n
WHERE x<(
SELECT max(seat_number)
FROM t1))
SELECT count(*)
FROM n
WHERE x NOT IN(
SELECT seat_number
FROM t1);
SELECT CASE seat_number%2 WHEN 0 THEN 'Even Numbers' ELSE 'Odd Numbers' END,count(*)
FROM t1
GROUP BY seat_number%2;
```

**Result and verification:** source correction: the 16 occupied seats include 7 even and 9 odd. The source lists 8 even seats. I-18 gives the same corrected count. Result 1: 4 rows. [[1,6],[8,12],[16,26],[36,51]] Result 2: 1 row. [[38]] Result 3: 2 rows. [["Even Numbers",7],["Odd Numbers",9]]

## Explanation

**Method and assumptions:** the query reports the ranges of missing seats, the total missing between seat 1 and the highest seat number, and the counts of occupied even and odd seats.

**Edge cases and trade-offs:** after occupying seat 1, the first gap is 2 through 6. There are 37 missing seats and 10 occupied odd seats.
