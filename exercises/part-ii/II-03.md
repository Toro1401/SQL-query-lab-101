**Input:** `t1(n)` (1 row).

## Question

How can you build text prefixes by appending the integers from 1 through n in order?

## Solution

```sql
WITH RECURSIVE r(n,s) AS(
SELECT 1,'1'
UNION ALL
SELECT n+1,s||(n+1)
FROM r
WHERE n<(
SELECT n
FROM t1))
SELECT s
FROM r;
```

## Results

| s |
| --- |
| 1 |
| 12 |
| 123 |
| 1234 |
| 12345 |

## Explanation

**Method and assumptions:** the query returns each growing prefix of the integers from 1 through n. It uses text to preserve the concatenated values.

**Edge cases and trade-offs:** with n=1, the only prefix is the text value 1.

```sql
UPDATE t1 SET n=1;
```
