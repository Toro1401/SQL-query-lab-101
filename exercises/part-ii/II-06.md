**Input:** `t1(n)` (1 row).

## Question

How can you generate every binary string of length n, including strings with leading zeros?

## Solution

```sql
WITH RECURSIVE bit(b) AS(VALUES('0'),('1')),r(s,k) AS(VALUES('',0)
UNION ALL
SELECT s||b,k+1
FROM r
CROSS
JOIN bit
WHERE k<(
SELECT n
FROM t1))
SELECT s
FROM r
WHERE k=(
SELECT n
FROM t1);
```

## Explanation

**Method and assumptions:** each row is a binary string of length n. Text preserves leading zeros.

**Edge cases and trade-offs:** length zero produces one empty string.

```sql
UPDATE t1 SET n=0;
```
