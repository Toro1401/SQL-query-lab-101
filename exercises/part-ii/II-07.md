**Input:** `t1(n, k)` (1 row).

## Solution

```sql
WITH RECURSIVE nums(x) AS(
SELECT 1
UNION ALL
SELECT x+1
FROM nums
WHERE x<(
SELECT n
FROM t1)),p(path,mask,k,last) AS(
SELECT '',0,0,0
UNION ALL
SELECT path||CASE WHEN k=0 THEN '' ELSE ',' END||x,mask|(1<<x),k+1,x
FROM p
CROSS
JOIN nums
WHERE (mask&(1<<x))=0)
SELECT path
FROM p
WHERE k=(
SELECT k
FROM t1);
```

**Result and verification:** result 1: 24 rows. [["1,2,3"],["1,2,4"],["1,3,2"],["1,3,4"],["1,4,2"],["1,4,3"]] … (see the report for the full output)

## Explanation

**Method and assumptions:** each row is an ordered selection of k distinct values from 1 through n. The recursion stops after k selections. The base fixture gives 24 triples.

**Edge cases and trade-offs:** with n=3 and k=2, all six ordered pairs appear without repeats.

```sql
UPDATE t1 SET n=3,k=2;
```
