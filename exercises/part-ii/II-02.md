**Input:** `t1(n)` (1 row).

## Solution

```sql
WITH RECURSIVE nums(x) AS(
SELECT 1
UNION ALL
SELECT x+1
FROM nums
WHERE x<(
SELECT n
FROM t1)),p(path,mask,k,last) AS(
SELECT '',0,0,0
UNION ALL
SELECT path||CASE WHEN k=0 THEN '' ELSE ',' END||x,mask|(1<<x),k+1,x
FROM p
CROSS
JOIN nums
WHERE (mask&(1<<x))=0)
SELECT (
SELECT n
FROM t1),path
FROM p
WHERE k=(
SELECT n
FROM t1);
```

**Result and verification:** result 1: 6 rows. [[3,"1,2,3"],[3,"1,3,2"],[3,"2,1,3"],[3,"2,3,1"],[3,"3,1,2"],[3,"3,2,1"]]

## Explanation

**Method and assumptions:** each row is a permutation of the integers from 1 through n. A bitmask prevents repeated elements. The number of rows grows factorially, so this approach is practical for small n.

**Edge cases and trade-offs:** with n=1, the only permutation is 1.

```sql
UPDATE t1 SET n=1;
```
