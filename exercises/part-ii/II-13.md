**Input:** `t1(row, col)` (1 row).

## Solution

```sql
WITH RECURSIVE c(k,v) AS(VALUES(0,1)
UNION ALL
SELECT k+1,v*((
SELECT row
FROM t1)-k)/(k+1)
FROM c
WHERE k<(
SELECT col
FROM t1))
SELECT v
FROM c
WHERE k=(
SELECT col
FROM t1);
```

**Result and verification:** result 1: 1 row. [[10]]

## Explanation

**Method and assumptions:** the query returns C(row,col) with zero-based indices. The integer multiplication formula gives C(5,2)=10 and is subject to signed 64-bit overflow.

**Edge cases and trade-offs:** C(5,0) is 1.

```sql
UPDATE t1 SET col=0;
```
