**Input:** `t1(order_id, line_item, cost)` (16 rows).

## Question

What is the maximum number of disjoint qualifying groups for each order, and what assignments reach it?

## Solution

```sql
WITH RECURSIVE options AS(
SELECT order_id,line_item a,line_item b,'('||line_item||')' label,1<<line_item mask
FROM t1
WHERE cost>=10
UNION ALL
SELECT a.order_id,a.line_item,b.line_item,'('||a.line_item||','||b.line_item||')',(1<<a.line_item)|(1<<b.line_item)
FROM t1 a
JOIN t1 b ON a.order_id=b.order_id AND a.line_item<b.line_item
WHERE a.cost+b.cost>=10),o AS(
SELECT *,row_number() OVER(PARTITION BY order_id
ORDER BY a,b) rn
FROM options),r(order_id,last,mask,k,labels) AS(
SELECT DISTINCT order_id,0,0,0,''
FROM t1
UNION ALL
SELECT r.order_id,o.rn,r.mask|o.mask,k+1,labels||CASE WHEN k=0 THEN '' ELSE ',' END||label
FROM r
JOIN o ON r.order_id=o.order_id AND o.rn>last AND (r.mask&o.mask)=0),ranked AS(
SELECT *,max(k) OVER(PARTITION BY order_id) best
FROM r)
SELECT order_id,k,nullif(labels,'')
FROM ranked
WHERE k=best;
```

## Explanation

**Method and assumptions:** each row describes a partition with the maximum number of groups for an order. Each group has one or two items and a cost of at least 10. Bitmasks keep groups disjoint, and items may go unused. Enumeration is exponential and uses integer row IDs from 1 through 62. Order 5 has one group per solution in the expected table, although the source comment says two.

**Edge cases and trade-offs:** an order with a single item costing 9 has zero qualifying groups and a NULL combination.
